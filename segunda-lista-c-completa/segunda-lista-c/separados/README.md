# Segunda Lista — Estruturas Condicionais

Cada arquivo `.c` é um programa independente, com seu próprio `main`. Compile um exercício com:

```bash
gcc -std=c17 -Wall -Wextra -Wpedantic arquivo.c -o programa
./programa
```

O exercício 2 usa `<string.h>` para comparar o estado civil. Os demais usam apenas `<stdio.h>` e não precisam de `-lm`.
